About
This project aims to bring Gravity Rush to PC as a native port, using the God of War native-port project as its technical starting point. The goal is to investigate what is needed to adapt the game's code and platform-specific systems for a native PC environment while preserving its distinctive gravity-based gameplay and comic-inspired art direction.
This is an early-stage community project. Features, compatibility, performance, and build instructions will be documented as development progresses.

Project Goals
- Explore a native PC implementation based on the existing God of War porting foundation.
- Investigate and implement the platform-specific systems required by Gravity Rush.
- Preserve the original gameplay, especially gravity shifting, traversal, and combat.
- Document technical findings, compatibility, and progress as the project develops.
These are project goals, not a statement that the features are already implemented.
